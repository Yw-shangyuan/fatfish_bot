# ops/docs 索引

这台服务器的说明书，给人看，也给 AI 看。

- `SERVER.md` — 硬件、系统、磁盘与内存、用户权限边界、目录地图、备份策略、安全待办
- `SERVICES.md` — 每个服务干什么、怎么起、配置和日志在哪、端口表、常用操作、已知坑
- `PLUGINS.md` — 三个插件的功能清单、QQ 消息决策链与风控旋钮（含运行时实值与生效状态）、模块与数据架构、隐患清单
- `HANDOFF-fishbox.md` — 鱼箱工具沙箱与炉石卡组解析的改动交接、待办、坑位
- `接入须知.md` — 接手本服的操作流程、权限边界与红线、验收自检

## 约定

1. 只写路径，不写密钥值（token、AK/SK、密码一律不进文档）
2. 改动服务、端口、备份策略时，顺手更新对应章节，并在下面记一行
3. 数据以实测为准：任何数字都标了采样时间，过期就重扫
4. 新增文档放本目录，命名用大写英文，正文用中文
5. 同一条事实只在一处维护，其余文档写指针；同一事实多处重复会互相引证出错误结论
