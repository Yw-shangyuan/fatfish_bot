## 四、QQ 主动伴聊 astrbot_plugin_qq_proactive（QQ 里主动说话的就是它）

| 指令 | 说明 |
|---|---|
| `/proactive` | 状态面板：开关、目标、时段、今日已发 X/上限、间隔 |
| `/proactive 开` / `关` | 开启 / 立刻闭嘴（持久化） |
| `/proactive 绑定` / `解绑` | 设定 / 清除主动消息目标会话 |
| `/proactive 测试` | 强制现发一条（无视间隔与时段，计入当日配额） |

数值参数（活跃时段 / 最小最大间隔 / 每日上限 / 人设）需去 WebUI 插件设置改。

## 五、不用指令也能玩：自然语言 LLM 工具

对着肥鱼说人话即可（`ENABLE_LLM_TOOLS` 开启时），它会自己调：
`bili_recall`（回忆）、`search_bilibili`（搜视频）、`watch_video`（看指定视频）、
`bili_action`（点赞/投币等）、`bili_bangumi`（番剧）、`bili_parse_video`（解析）、
`bili_watch_videos`（触发一次主动看视频）、`bili_block_user`（拉黑，需管理权限）。
