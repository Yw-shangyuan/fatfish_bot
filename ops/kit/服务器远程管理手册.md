QQ 登录态存在磁盘里（`/srv/napcat/qqdata`），重启不丢登录；只有被腾讯踢下线才需要重新扫码。

## 三、出问题怎么办（对号入座）

| 症状 | 处理 |
|---|---|
| 发消息机器人不回 | 菜单[2]体检 → 若 AstrBot 不是 active：菜单[3] 输 `sudo systemctl restart astrbot` |
| QQ 显示离线/掉线 | 菜单[1] 开 NapCat 面板看是否要扫码；多数情况它自己会重连。重启：`sudo docker restart napcat` |
| **需要重新扫码登录** | 菜单[1] NapCat 面板 → 左侧「NapCat 登录」页里有二维码；或手机 QQ 扫（注意 2 分钟内扫完并点确认，超时二维码作废，`sudo docker restart napcat` 换新的） |
| 半夜挂了想远程拉起来 | 手机装 Termius App → SSH 连 `ubuntu@101.34.204.107` → 跑下面的命令 |
| 想彻底重启两件套 | `sudo systemctl restart astrbot && sudo docker restart napcat` |
| 体检说内存吃紧 | `sudo journalctl -u astrbot --since '30 min' -p err` 看是否插件报错刷屏 |

### 命令速查（SSH 里用）

```bash
systemctl status astrbot          # 大脑状态
sudo systemctl restart astrbot    # 重启大脑
docker ps                         # QQ 容器在不在
sudo docker restart napcat        # 重启 QQ（一般不掉登录）
sudo journalctl -u astrbot -n 50 --no-pager   # 最近 50 行日志
df -h /                           # 磁盘
free -m                           # 内存
```
