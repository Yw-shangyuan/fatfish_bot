## 一、这套系统是什么

```
手机/电脑 QQ
      │ (腾讯服务器中转，不需要公网开放任何 QQ 端口)
      ▼
┌──────────────── 腾讯云 101.34.204.107 ────────────────┐
│  Docker 容器: snowluma（QQ 协议端，负责收发 QQ 消息）  │
│        │  OneBot v11 / ws://127.0.0.1:6199            │
│        ▼                                              │
│  systemd 服务: astrbot (AI 大脑、插件、知识库)         │
│     ├─ 6185 Web 管理面板 (仅本机，需隧道)             │
│     ├─ 插件: bilibili_ai_bot (B站盯梢推送)            │
│     └─ 插件: qq_proactive (QQ 主动消息)               │
│  SnowLuma 面板: noVNC 6081 / WebUI 5099 (仅本机)      │
└───────────────────────────────────────────────────────┘
      │
      ▼ (出站调用)
 DeepSeek API (聊天模型) / 硅基流动 (向量模型)
```

**两件套都是开机自启**：服务器重启后 snowluma 容器（`unless-stopped`）和 AstrBot（systemd）会自己起来。
QQ 登录态在磁盘 `/srv/snowluma/`（`config`→`/app/.config`、`local`→`/app/.local/share`、`data`→`/app/data`），重启不丢登录；只有被腾讯踢下线才需要重新扫码。

> 归档：SnowLuma 2.2.0 可运行副本在私有仓库 `gitee.com/YwShangyuan/snowluma-archive`；镜像 tar 冷备在服务器 `/home/ubuntu/cold-storage/snowluma-2.2.0-20261024.tar`。

## 二、日常使用：三步走

### 第 1 步：双击 `远程控制台.cmd`

第一次在新电脑上用，先选 **[4]** 配置免密（显示 `KEYLESS_OK` 即成功）。本公司的电脑已配好免密。

### 第 2 步：菜单功能速查

| 菜单 | 功能 | 什么时候用 |
|---|---|---|
| **1** | 打开 Web 面板 | 改配置、装插件、看聊天记录 |
| **2** | 服务器体检 | 感觉机器人不对劲，先看报告 |
| **3** | SSH 命令行 | 高级操作 |
| **4** | 配置免密 | 新电脑第一次 |
| **5** | AstrBot 实时日志 | 排查 AI/插件问题 |
| **6** | SnowLuma 实时日志 | 排查 QQ 收发/登录问题（`docker logs -f snowluma`） |

### 第 3 步：面板怎么用

| 面板 | 地址 | 登录 | 管什么 |
|---|---|---|---|
| **AstrBot** | `http://127.0.0.1:6185` | 用户 `ywsy` | AI 模型、插件、知识库、QQ 平台配置、B站插件设置 |
| **SnowLuma noVNC** | `http://127.0.0.1:6081` | VNC 密码见容器环境变量 | QQ 桌面、扫码登录、登录状态 |

> SnowLuma 的 VNC 密码不写进文档；需要时在服务器上执行 `docker inspect snowluma` 查看环境变量 `VNC_PASSWD`。
> 面板打不开？菜单 [2] 体检；全绿还打不开＝隧道进程死了，菜单 [0] 退出重开。

## 三、出问题怎么办（对号入座）

| 症状 | 处理 |
|---|---|
| 发消息机器人不回 | 菜单[2]体检 → 若 AstrBot 不是 active：`sudo systemctl restart astrbot` |
| QQ 显示离线/掉线 | 看 `docker logs --tail 100 snowluma`；多数情况会自己重连。重启：`sudo docker restart snowluma` |
| **需要重新扫码登录** | 隧道打开 `http://127.0.0.1:6081`（noVNC），在 QQ 桌面里扫码；2 分钟内扫完并确认 |
| 半夜挂了想远程拉起来 | 手机 Termius → SSH 连 `ubuntu@101.34.204.107` → 跑下面命令 |
| 想彻底重启两件套 | `sudo systemctl restart astrbot && sudo docker restart snowluma` |
| 体检说内存吃紧 | `sudo journalctl -u astrbot --since '30 min' -p err` 看是否插件报错刷屏 |

### 命令速查（SSH 里用）

```bash
systemctl status astrbot              # 大脑状态
sudo systemctl restart astrbot        # 重启大脑
docker ps                             # QQ 协议容器在不在（应为 snowluma）
sudo docker restart snowluma          # 重启 QQ 协议端（一般不掉登录）
docker logs --tail 100 snowluma       # 协议端日志
sudo journalctl -u astrbot -n 50 --no-pager   # 最近 50 行日志
df -h /                               # 磁盘
free -m                               # 内存
```

## 四、手机应急方案（身边只有手机时）

1. 装 **Termius** → 新建连接：host `101.34.204.107`，用户 `ubuntu`
2. 机器人挂了？直接敲：`sudo systemctl restart astrbot; sudo docker restart snowluma`
3. 手机上想用面板：Termius 付费版支持端口转发（6185/6081），免费版就只敲命令吧
